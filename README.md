# JSON Tree Visualizer

> Started to build this project when no tool can visualize a very large json in a tree structure


### What it solves?
Gives the ability to visualize the JSON as nodes and edges in 2D canvas. 

### How it is achieved?
It renders the nodes and edges which shown in the viewport, it doesn't matter how many nodes are generated by the json

### Additional support & features
- Fully customizable nodes, edges, text and background colour
- Adjustable spacing between the nodes and edges
- JSON Renderer alone is available as an NPM package

---

## Getting Started

```bash
npm install
npm run dev
```
