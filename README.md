# JSON Tree Visualizer

> Started building this project when there was no such tool to visualise a very large json in a tree format


### What does it solve?
Gives the ability to visualise the JSON as nodes and edges on a 2D canvas. 

### How is it achieved?
It renders the nodes and edges that are shown in the viewport; it doesn't matter how many nodes are generated by the json

### Additional support & features
- Fully customizable nodes, edges, text and background colour
- Adjustable spacing between the nodes and edges
- JSON Renderer alone is available as an NPM package: [react-json-tree-visualizer](https://www.npmjs.com/package/react-json-tree-visualizer)
